Proza playground

Editor

  • Forms: the editor in a host form: an enhanced textarea, the custom element and the Vue component.
  • Editor: the field with its interface: part tools, add menu and /, part options, format bubble, status line, outline, help, source.

Spikes

  • Rich-text field: typing, formats, Enter, Backspace, undo, with an input event log for device testing.
  • EditContext field: the same field on the EditContext API (Chromium only).
  • Canvas isolation: light DOM and shadow DOM under hostile host CSS.
  • Screen reader structures: three ways to expose blocks, for NVDA, JAWS, VoiceOver and TalkBack.
  • Reka UI in a shadow root: popover, menu and toolbar inside the editor's shadow root.

Tools

  • Clipboard capture: record paste payloads from Word, Google Docs and others as test fixtures.
